# quickpad

A 3x3 macropad with 8 buttons and an encoder

Links to an app on my computer, change mode through the encoder and use the buttons to activate various shortcuts <br>
Shortcuts are streamed to the app which executes things (usually powershell commands) <br>
Still looking for ideas as there is an infinite number of things i can assign keys to (through changing mode through encoder) <br>

PLEASE NOTE THIS IS MADE FOR PERSONAL USE <br>
It has not been designed so that someone else would be able to use it, <br>
